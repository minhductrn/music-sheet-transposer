# Advanced Editing v1 — implementation contract

Authorized by the Product Owner on October 31, 2026, after design approval. Base: accepted UX Next RC1 commit 91d74a3. Classic and RC1 packages remain immutable.
Scope: contiguous complete measures, one part and one staff, all voices preserved; explicit copy/transpose/append to end with double barline and destination key, including chord symbols. Mouse measure selection and compact source/step/destination controls, 0.5-tone increments, editable source key, preview/apply/cancel, atomic undo/redo and MusicXML persistence. Reuse the same key shift control in Concert Key while preserving Up/Down and octave functionality.
Allowed: review section module/models/service/routes; optional exact concert interval endpoint; shared frontend controls/section panel/measure-selection overlays; tests, English docs and independent packaging. Exclude multipart expansion, arbitrary middle insertion, nested/cross-bar tuplet authoring, cloud, agents and Classic changes. Boundary ties/slurs/tuplets must be contained; ask the user to extend selection rather than infer links. Existing original measures and private scores must not be rewritten. Preview must not mutate the review; Apply must check revision and regenerate from the same request.
Technical verification and source review precede Product Owner acceptance. Git commit/push requires separate explicit authorization.
