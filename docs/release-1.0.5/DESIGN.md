# Music Sheet Transposer 1.0.5 — Design

Direct Text objects occupy existing header whitespace without adding rows or moving staves. Click Text then the header, type and press Enter. Drag within the header. Select an object to edit/delete. Generated Concert-key and instrument labels use the same interaction. Stage 1/2 and Compare/Edit Only share the tools.

Existing limits remain: local deployment only; OMR is a draft, not guaranteed correct; dense engraving collisions, multipart expansion and nested/cross-bar tuplet authoring are not newly resolved. Camera capture, Web Share API and cloud deployment are excluded. No general OMR accuracy certification is claimed.
