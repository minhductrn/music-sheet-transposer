# Music Sheet Transposer 1.0.4 — Operations

Save all scores before closing an older session. Run python3 -B /home/dtran/music-sheet-transposer-releases/music-sheet-transposer-1.0.4/start.py --check and then the same command with --port 5250. If occupied, select another port. Keep 1.0.2 and older packages unchanged for rollback. This bundle requires the recorded Ubuntu/Python ABI and existing Audiveris, Java and vie/eng OCR models. It installs nothing. Retained MusicXML is the recovery format; unsaved sessions are temporary.

Existing limits remain: local deployment only; OMR is a draft, not guaranteed correct; dense engraving collisions, multipart expansion and nested/cross-bar tuplet authoring are not newly resolved. Camera capture, Web Share API and cloud deployment are excluded. No general OMR accuracy certification is claimed.
