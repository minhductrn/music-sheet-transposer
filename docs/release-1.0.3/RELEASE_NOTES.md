# Music Sheet Transposer 1.0.3 — Release Notes

The Product Owner accepted Text creation, drag/edit/delete, compact header spacing, generated output labels and independent selection of legacy/new equal text on 2026-11-01, and authorized commit/push and official release. The centered 85% PDF lyric setting and accepted musical behavior remain unchanged.

Existing limits remain: local deployment only; OMR is a draft, not guaranteed correct; dense engraving collisions, multipart expansion and nested/cross-bar tuplet authoring are not newly resolved. Camera capture, Web Share API and cloud deployment are excluded. No general OMR accuracy certification is claimed.
